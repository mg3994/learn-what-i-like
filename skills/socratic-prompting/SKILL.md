## 1. The Physics of Socratic Prompting

### The Failure of Direct Code Barking
Telling an AI agent directly *"Fix line 42 by wrapping it in an if-null check"* turns the software engineer into an exhausted human compiler. This creates **Somatic Recoil**: the LLM applies a local patch that violates global invariants or introduces regressions elsewhere in the codebase.

### Alpha-Beta Pruning Analogy
In chess engines, Alpha-Beta pruning evaluates move trees and discards bad branches early without exploring their deep sub-trees. Socratic Prompting acts as Alpha-Beta pruning for LLMs: a targeted constraint question prunes an entire sub-tree of flawed solutions at **depth $d=1$**.

```
                       [ User Prompt ]
                              │
               ┌──────────────┴──────────────┐
               ▼                             ▼
    [ Flawed Happy-Path ]           [ Constraint Question ]
  (Explores 1,000 bad tokens)        ("What if the stream throws?")
               │                             │
               ▼                             ▼
    [ Somatic Recoil Crash ]         [ Pruned Bad Branch at d=1 ]
                                             │
                                             ▼
                                    [ Robust Architecture ]
```

## 2. The NLP Meta-Model Framework for Code Review

The **NLP Meta-Model** identifies language patterns that obscure reality. Apply these 3 categories to code review prompts:

### 1. De-deletion
- **LLM Pattern**: Ignores edge cases or cleanup handlers (e.g. unclosed StreamSubscriptions).
- **Socratic Prompt**: *"What happens to this subscription when the parent widget unmounts during an active request?"*

### 2. De-distortion
- **LLM Pattern**: Assumes async operations always complete in dispatched order.
- **Socratic Prompt**: *"If Request B returns before Request A, how does the state machine prevent stale data overwrites?"*

### 3. De-generalization
- **LLM Pattern**: Uses blanket error catches (`catch (e) {}`).
- **Socratic Prompt**: *"Under what specific failure modes does this throw a SocketException vs a FormatException, and how are they distinguished in state?"*

## 3. Socratic Steering Template for Coding Agents

When directing an AI agent to build or refactor a module, use this 3-question steering structure:

```markdown
1. **Invariant Check**: What architectural invariant guarantees that this state cannot be updated concurrently from two isolates?
2. **Failure Boundary**: What specific Exception type handles a network timeout after 3 seconds, and how does the UI surface it?
3. **Lifecycle Check**: How is memory freed when the controller is disposed?
```
